# Third-party dependencies

## VST3 interfaces

`third_party/pluginterfaces` contains Steinberg VST3 public interface headers.
Copied unchanged from the locally available `NativePluginConverter/native/third_party/pluginterfaces` at project revision `12198e85372566ed2f94696c316ae39ea666bef4`.
Upstream: https://github.com/steinbergmedia/vst3_pluginterfaces
License: MIT, preserved in `third_party/pluginterfaces/LICENSE.txt` and in each release bundle.
No converter/bridge implementation code is used by Essential Sampler.

## libFLAC 1.5.0 and libogg 1.3.6

Public libFLAC headers and ARM64 static libraries were copied from the locally installed Homebrew distributions. The archives target macOS 27.0 and are linked into the executable; there are no runtime Homebrew dependencies.

- FLAC source: https://github.com/xiph/flac/tree/1.5.0
- Ogg source: https://github.com/xiph/ogg/tree/v1.3.6
- Licenses: BSD-style Xiph licenses in `third_party/flac/LICENSE` and `third_party/ogg/LICENSE`, also included in release bundles.
- Only libFLAC and libogg are linked. The `flac` CLI used to produce a generated test fixture is not shipped.

The test fixture contains a generated one-second stereo sine wave. The built-in demo is generated by `makeDemo()` from mathematical oscillators; no external sample library is included.


## dr_libs (Windows audio decoding)

`third_party/dr_libs/dr_wav.h` and `dr_flac.h` are from [mackron/dr_libs](https://github.com/mackron/dr_libs/tree/f12e197fd462e4c22873fbd70d11b1d2f2c1dc3c), revision `f12e197fd462e4c22873fbd70d11b1d2f2c1dc3c`. Their MIT No Attribution (MIT-0) / public-domain licensing options are preserved in `third_party/dr_libs/LICENSE` and the headers. Windows packages include the license. These decoders have no external runtime dependencies.
