# FX and host keyboard focus

User request: a separate FX tab with distortion and chorus; fix Backspace still captured by the editor.

Use the current dark native Cocoa editor. Sampler and FX tabs share the header, Output, piano and voice display. FX contains two side-by-side modules in series: summed sampler voices → Distortion → Chorus → Output. Controls: Distortion enable, type (Tube, Saturate, Clipping, Asymmetrical, Scream, Aliasing), Amount, Tone, Mix; Chorus enable, Depth, Rate, Width, Delay, Feedback, Mix. Both default off so existing projects sound unchanged. Append automation IDs, accept old state parameter counts 9/v1 and 12/15/v2. Smooth continuous DSP controls and bypass; allocate delay buffers only in prepare. No preview/panic buttons.


Alternative direct Intel linkage cannot serve the ARM target; full exact reverse engineering requires a configured decompiler and behavioral comparison. Proceed with native implementation per request, document the limitation.

Hosted views must not acquire first-responder status from mouse controls. DAW owns computer keyboard/MIDI; standalone retains built-in note keys. Text fields keep editing Backspace locally, then relinquish focus on commit. Mouse piano and MIDI remain supported.
