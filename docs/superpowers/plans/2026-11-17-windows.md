# Windows release implementation

1. Add an allocation-free portable FFT backend and test it against the existing DSP regressions.
2. Add portable WAV/AIFF/FLAC decoding with malformed-file and Unicode-path tests.
3. Implement the native Windows editor and standalone around the shared Model/Engine interfaces.
4. Adapt the shared VST3 wrapper and host test to HWND/DLL loading without changing identities.
5. Add CMake, Windows CI, packaging and an installer with backups; run tests on Windows.
6. Remove obsolete third-party product mentions from maintained files and release descriptions; update English platform/build docs and versions to 0.7.0.
7. Rebuild and test macOS, review the Windows artifacts and screenshot, then publish verified archives, source and checksums as a stable release.

Steps 1–3 are independent with separate file ownership. Integration and publication remain sequential. Existing macOS registry restrictions must remain visible in verification documentation.
