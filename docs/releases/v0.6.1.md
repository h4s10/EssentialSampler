Installation and documentation update for EssentialSampler, displayed in DAWs as **hasio / Hasio Loop**.

## What's new

- AU installation now checks whether macOS has registered the component before starting validation.
- Removes download quarantine only from the signature/identity-verified Hasio Loop bundle; refreshes the current user's registrar if needed and retries discovery briefly.
- Forces native arm64 AU validation, separates "not registered" from an actual validation failure, and retains failed validation logs.
- Adds **Repair-AU.command** to repair an existing 0.6.0 installation without replacing its binary.
- English README, user guide and developer documentation, with real sampler and FX screenshots included in the repository and downloadable archives.

## Install / repair

Close your DAW, unzip **AU**, **VST3** or **all**, then run **Install.command**. Existing plugin versions are backed up.

For the 0.6.0 `FATAL ERROR: didn't find the component` error, use this installer or run **Repair-AU.command**. If macOS still does not register the component, restart your Mac once. Logic: **AU Instruments → hasio → Hasio Loop → Stereo**.

## Downloads

- **AU**: Audio Unit `.component` for Logic and other AUv2 instrument hosts.
- **VST3**: plugin for Ableton Live and other VST3 hosts.
- **all**: both plugin formats plus the standalone app.
- **source**: source code and bundled build dependencies.
- **SHA256SUMS.txt**: archive checksums.

**Apple Silicon / macOS 27+ only.** Ad-hoc signed, not Developer ID signed or notarized. MIT project license; dependency notices included.

## Verification and limits

This remains a prerelease. Installer tests reproduce stale/missing registration, quarantine, repair, signature rejection and validation errors using a mocked OS registry. DSP, VST3, UI and AU direct-interface tests are covered separately. The build sandbox cannot access the system AudioComponent registry, so neither the reported discovery problem nor Logic/Apple auval compatibility can be confirmed as resolved on the target Mac yet. The installer performs that real check when run locally. Audio processing is unchanged from 0.6.0.
