The plugin is now named **Essential Sampler** throughout its interface and host-facing metadata.

## What's changed

- **Essential Sampler** in the Sampler/FX editor, DAW plugin lists, standalone window/menu and accessibility labels.
- Bundles are now **Essential Sampler.vst3**, **Essential Sampler.component** and **Essential Sampler.app**.
- README and included documentation use the new name, with fresh screenshots from the actual native editor.
- The installer backs up old **Hasio Loop** bundles before installing the renamed versions, preventing duplicate plugin identities. Failed replacement restores the previous bundles.

Internal VST3/AU IDs, bundle identifiers, parameter IDs, embedded-sample state and DSP behavior are unchanged. Existing sessions can continue identifying the instrument by the same IDs; a host rescan may be needed to refresh the displayed name.

## Upgrade

Close your DAW, download **AU**, **VST3** or **all**, unzip it and run **Install.command**. Use the installer rather than leaving both old and new bundles in a plugin folder. In Logic: **AU Instruments → hasio → Essential Sampler → Stereo**.

**Apple Silicon, macOS 27+**. AU and VST3 are available separately; **all** also includes the standalone app. **source** contains source code and bundled build dependencies. SHA-256 checksums are included.
