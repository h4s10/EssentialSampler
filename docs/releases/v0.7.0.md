Essential Sampler 0.7.0 adds native **Windows x64** builds alongside **macOS Apple Silicon**. This is the first stable release.

## Downloads

| Platform | Package | Contents |
| --- | --- | --- |
| macOS 27+, arm64 | `macOS27-arm64-AU` | Audio Unit for Logic and other AUv2 instrument hosts |
| macOS 27+, arm64 | `macOS27-arm64-VST3` | VST3 instrument |
| macOS 27+, arm64 | `macOS27-arm64-all` | AU, VST3 and standalone app |
| Windows 10/11, x64 | `Windows-x64-VST3` | VST3 instrument |
| Windows 10/11, x64 | `Windows-x64-all` | VST3 and standalone executable |
| Source | `source` | Source code, tests and bundled build dependencies |

All archives include English documentation and dependency licenses. SHA-256 checksums are provided in **SHA256SUMS.txt**.

## What's new

- Native Windows editor with dual waveforms, loop editing, pitch/time controls, musical sync, FX and keyboard.
- Portable FFT backend and WAV/AIFF/FLAC decoding, including Unicode file paths.
- Windows installer with checksum verification, staged replacement and previous-version backups.
- Native Windows CI exercises DSP, real VST3 loading/rendering, editor behavior, sample import and the installed release package.
- Existing plugin IDs, parameter IDs and embedded-sample state are preserved. macOS retains its native Cocoa editor and Accelerate processing.
- Updated English documentation and project branding, with refreshed macOS screenshots.

## Install

Close your DAW and extract the complete archive. On **macOS**, run **Install.command**; AU repair is available through **Repair-AU.command**. On **Windows**, run **Install.cmd** and accept the administrator prompt, or copy the complete **Essential Sampler.vst3** folder into **C:\Program Files\Common Files\VST3**. Reopen/rescan your DAW and select **hasio → Essential Sampler**.

The **all** archive also includes a standalone app/executable that can run directly from its extracted folder. Windows standalone uses the default output device; VST3 uses your DAW audio driver.

## Verification and limits

macOS build, DSP sanitizers, native VST3/Cocoa UI tests, direct AU interface tests and installer regressions pass. Windows is compiled and tested natively with MSVC; the installed VST3 is loaded by an automated host. These tests do not replace manual testing in every DAW. Independent system AU validation, commercial Windows DAW integration, Windows hardware audio output and physical touchpad gestures remain unverified in the build environment. See the repository's **docs/VERIFICATION.md** for details.

Apple Silicon and Windows x64 only; no Intel Mac, Windows ARM or 32-bit builds. Pitch/time processing has a fixed 2048-sample latency and can soften transients at extreme settings. Windows binaries are unsigned; macOS binaries are ad-hoc signed and not notarized. Project license: **MIT**; dependency licenses are included.
