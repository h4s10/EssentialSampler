First public EssentialSampler release. The instrument appears in DAWs as **hasio / Hasio Loop**.

## Downloads

- **VST3** — for Ableton Live and other VST3 hosts.
- **AU** — native AUv2 `.component` for Logic Pro.
- **all** — both plugin formats plus the standalone app.
- **source** — source tree and bundled build dependencies.
- **SHA256SUMS.txt** — archive checksums.

**Requirements: Apple Silicon, macOS 27 or newer.** Intel, Windows and older macOS builds are not included.

## Included

Dual waveform views, trackpad zoom/panning, movable loop ranges, five playback modes, independent pitch/time controls, note/bar sync to host tempo, fades/envelope, 16 voices, distortion and chorus. Samples are embedded in DAW project state. AU and VST3 share the same DSP and interface.

Unzip the desired archive, close your DAW and run `Install.command`. Existing plugin versions are backed up. AU installs into `~/Library/Audio/Plug-Ins/Components`; VST3 into `~/Library/Audio/Plug-Ins/VST3`. Logic: **AU Instruments → hasio → Hasio Loop → Stereo**.

## Validation / known limits

Native build, DSP/FX tests, VST3 host tests, Cocoa keyboard/UI tests and AU direct-interface tests pass. AU regression tests cover MIDI timing, automation, state, buffers and lifetime. The sandbox does not expose the system AudioComponent registry, so Apple auval and Logic integration have **not** been confirmed. This prerelease is intended for that final host check; the AU installer runs auval automatically. If needed, use Logic's Plug-in Manager → Reset & Rescan Selection.

Binaries are ad-hoc signed, not Developer ID signed/notarized. macOS may require confirmation in Privacy & Security. Pitch processing has a fixed 2048-sample latency and can soften transients, especially under extreme time compression.
